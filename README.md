# C++ Practice Programs

A simple collection of C++ programs for learning selection statements and loops.

## Folders

| Folder | What's inside |
|--------|---------------|
| `01-Simple-Selection` | Programs using `if` and `if-else` |
| `02-Complex-Selection` | Programs using nested `if`, `if-else if`, `switch`, and logical operators (`&&`, `||`, `!`) |
| `03-Iterative-Loops` | Programs using `for`, `while`, and `do-while` loops |

## How to Run

```bash
g++ filename.cpp -o program
./program
```
